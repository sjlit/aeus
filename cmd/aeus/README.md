# aeus CLI

Scaffold a new AEUS project:

```bash
go run ./cmd/aeus new my-service
go run ./cmd/aeus new my-admin --template=admin
```

Flags:

| Flag | Default | Meaning |
|---|---|---|
| `--template` | `minimal` | `minimal` or `admin` |
| `--module` | project name | Go module path (`github.com/acme/my-service`) |
| `--local` | auto-detected in a source checkout | emit `replace` directives to a local AEUS checkout |
| `--force` | false | write into a non-empty directory |

The generated project runs `go mod tidy` at the end. The web app in the
`admin` template is built separately with `make web`.

After `make proto` in a generated project, wire the generated business
resources into admin:

```bash
aeus gen
aeus gen --check   # CI drift check
```

`aeus gen` reads `_aeus.json` manifests under `proto/`, rewrites
`internal/gen/wiring.go`, creates missing
`web/src/views/<module>/<singular>/Index.vue` placeholder pages, and
generates TypeScript interfaces plus custom-RPC wrappers under
`web/src/api/generated/`. TS generation covers enums, nested messages,
cross-file imports and well-known types. Previously generated TS files
(with the `Code generated by aeus gen` header) are refreshed; files
without that header are treated as hand-written and never overwritten.
Vue placeholders are only created when missing so hand-written pages
survive.

| Flag | Default | Meaning |
|---|---|---|
| `--proto-dir` | `proto` | manifest directory |
| `--out` | `internal/gen` | generated Go directory |
| `--package` | `gen` | generated Go package |
| `--file` | `wiring.go` | generated Go file |
| `--web-dir` | `web/src/views` | Vue views directory |
| `--api-dir` | `web/src/api/generated` | TypeScript API directory |
| `--no-web` | false | skip Vue page generation |
| `--no-api` | false | skip TypeScript API generation |
| `--check` | false | verify generated Go/Vue/API outputs (TS content, Vue presence) |

## Templates

- `templates/minimal`: HTTP + config + logging + health + graceful shutdown.
- `templates/admin`: minimal + GORM/SQLite + admin REST/RPC + JWT/RBAC
  + Seed + Vue 3 management console. It also ships `proto/`, `buf`
  configuration and a `proto/shop/v1/order.proto` business example so
  new resources can be generated with `make proto`. Startup code lives
  in `internal/app`; generated wiring lives in `internal/gen`.

Template files use `__AEUS_*__` placeholders. Files ending in `.tmpl`
are written without that suffix (notably `go.mod` and the Go sources,
so the Go toolchain does not treat the template tree as part of the
root module).

The admin web console is generated from `admin/web` with:

```bash
make sync-web   # equivalent to: go generate ./cmd/aeus
```

Template-owned files (`README.md`, `.gitignore`, the smoke test and
`src/components.d.ts`) are preserved; everything else is copied with the
scaffold placeholders applied. CI runs the generator and fails on drift.

## Releases

`versions.json` holds the versions embedded into generated `go.mod`
files. Update it in the same coordinated release that tags the root,
`transport/http` and `admin` modules. Until then, source checkouts use
the auto-detected `--local` path.
